# Building a GPT: From Scratch

A scratch implementation of a GPT LLM using Python and Pytorch

The goal of this project is not simply train a Large Language Model, but to understand how a GPT works internally by implementing it step by step instead of treating it as a black Box.

## Setup

### 1. Clone the Repository

`git clone https://github.com/MPRohit0/gpt-from-scratch` \
`cd gpt-from-scratch`

### 2. Create the Conda environment

`conda env create -f environment.yml`

### 3. Activate the environment

`conda activate gpt-from-scratch`
